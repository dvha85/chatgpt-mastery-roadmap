# Evidence — Cách lưu bằng chứng

Evidence chứng minh bạn đã thực hiện và kiểm tra bài; không phải lời xác nhận đã đọc.

## Tối thiểu

- Lesson ID, ngày, surface và source snapshot.
- Task/input, prompt, kết quả quan sát được.
- Verification, failure mode, tự chấm và reflection.

## Cách lưu

- Private notes cho dữ liệu công việc.
- Private repository độc lập nếu muốn dùng GitHub; fork của repo public vẫn public.
- Public repo chỉ dùng dữ liệu giả lập hoặc dữ liệu được phép công khai.

## Trước khi commit

- [ ] Không có password, token, API key, cookie hoặc secret.
- [ ] Không có dữ liệu cá nhân/khách hàng không cần thiết.
- [ ] Link chat/file/ảnh không làm lộ dữ liệu riêng tư.
- [ ] Có cách kiểm tra cho claim hoặc requirement.
- [ ] Tên file bắt đầu bằng lesson ID.

## GitHub web

Mở private repository độc lập hoặc fork public chỉ dành cho dữ liệu công khai → **Add file** → tạo file trong `evidence/` → dán template → Preview → kiểm tra privacy → commit. Dán link file vào cột Evidence trong PROGRESS của bản repo cá nhân.

Không cần lưu link cuộc chat nếu nội dung không thể chia sẻ an toàn.

## Rubric nhanh

Chấm 0–2 cho từng năng lực: `0` chưa làm/sai cốt lõi; `1` làm một phần hoặc cần gợi ý; `2` tự làm đúng và có verification. Một bài chỉ PASS khi có Execute và Verify, không có năng lực cốt lõi nào bằng 0. Chi tiết riêng của từng lesson có thể nghiêm ngặt hơn.

Xem [GitHub fork visibility](https://docs.github.com/en/pull-requests/reference/forks) trước khi chọn nơi lưu.
