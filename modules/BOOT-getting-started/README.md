# BOOT — Getting Started / Khởi động

## Outcome / Kết quả
Sau module này, người mới có thể mở chat, gửi yêu cầu, tinh chỉnh response, kiểm tra một claim và lưu evidence sạch.

## Study rule
Làm theo thứ tự. Mỗi bài 20–40 phút; dùng dữ liệu giả lập; chỉ chuyển bài sau khi evidence đạt rubric.
